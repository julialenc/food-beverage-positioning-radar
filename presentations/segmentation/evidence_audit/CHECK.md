## Scope and limits

The 35 legacy reuses retain saved OCR, extracted results and source provenance, but original image bytes and raw model envelopes were not found. See [the case register](historical_gaps.json). This is a package of all retained evidence, not a claim that those missing originals have been recovered.

Sampling choices and human decisions remain fixed historical inputs. Exploratory selection-model fits and human judgments are not repeated. The recorded installed Python environment was reused.

Harness corrections, failed attempts and source revisions are retained in `outputs/ocr_llm_evidence_isolation_v1/`. Passed earlier stages were retained only after their scientific-source hashes were rechecked. Final source assets must match the executed scientific code; data assets must remain identical to the verified restoration. The final asset attestation is staged at `outputs/ocr_llm_evidence_candidate_v1/final_verification.json`.

The [machine-readable validation report](VALIDATION.json), [scope](RELEASE_SCOPE.md) and [manifest](manifest.json) provide the detailed identities. The 35-case evidence gap remains disclosed in the release notes and case register. Public download verification is reported on the release page; it does not repeat the full analytical run. The separately approved root README is preserved.
