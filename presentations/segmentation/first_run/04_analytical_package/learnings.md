# Consolidation learnings

- A canonical rerun can reuse frozen commercial decisions and approved rules without executing exploratory research.
- Runtime inputs, independent equivalence references and research decision evidence have different retention roles. Removing a research script from runtime does not authorize deleting it.
- Full master grain, question-specific profile eligibility and sparse separate claims preserve uncertainty; a missing join is never a negative claim.
- Existing prototypes should consume the accepted data contract after analytical acceptance.
- Presentation must distinguish uninvestigated formats from studied variation, insufficient evidence, scope exclusions and unresolved identity. The internal catch-all is not a public research conclusion.
- All three canonical code files are protected release dependencies. Frozen v1 rejects overwrite; verifier checks integrity without writing.
