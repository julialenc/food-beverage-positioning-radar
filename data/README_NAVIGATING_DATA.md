Folder contract:

- `data/01_reference_inputs/` is the only committed production input folder under `data/`.
- `data/02_raw_off_downloads/` is regenerated by stage 01A or 01B from public Open Food Facts sources.
- `data/03_pipeline_intermediates/` is regenerated by the core OFF pipeline stages; stage 04 consumes the stage 03 `nutrition_quality_<timestamp>.csv` handoff.
- `data/04_vision_sampling/` is regenerated before paid/manual pack-image analysis.
- `data/05_vision_release/` is regenerated or curated during paid/manual pack-image release runs.
- `data/06_brand_governance_outputs/` is regenerated by category and brand/company governance tools.
- `data/07_nutrition_quality_outputs/` is regenerated by nutrition-quality flagging and historical review tools.
- Generated outputs remain ignored unless explicitly promoted to committed production reference inputs.
- Pipeline-run outputs should include a run timestamp in the filename or database metadata where practical.
- Open Food Facts is live and crowdsourced, so a fresh download can differ from a prior timestamped run.
- Azure credentials are required only for the paid OCR/LLM vision extraction stage.
- `data/nutrition_outlier_review/` may exist locally as an ignored legacy audit folder; it is not part of the repo tree.
